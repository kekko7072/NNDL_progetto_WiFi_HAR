\section{Introduction}
\label{sec:introduction}

Contactless sensing of human activity is valuable in healthcare, security and
ambient monitoring. Commodity Wi-Fi devices can be repurposed as radar-like
sensors: as a person moves, their body induces micro-Doppler shifts captured in
the channel-state information (CSI) estimated by the receiver, \emph{without
recording any video}. After processing, the CSI becomes a \emph{Doppler
spectrogram}---a time$\,\times\,$velocity image---whose appearance changes
markedly with the activity, so recognition can be cast as image classification
with a convolutional neural network (CNN)~\cite{sharp}.

The central difficulty is \emph{generalization}. Different people move
differently, and different rooms (and even the same room on different days)
distort the signal differently, so a model that classifies perfectly in its
training environment may collapse on a new one. This is the challenge raised in
the project proposal, which explicitly suggests a
\emph{contrastive / self-supervised} approach to obtain subject- and
environment-independent features. Prior systems close this gap mostly through
signal processing---robust phase sanitization and multi-antenna fusion---at the
cost of a heavy, hand-engineered pipeline~\cite{sharp}; we instead ask how far a
purely \emph{representation-learning} remedy can go on top of a minimal
front-end.

In this report we tackle five-class Wi-Fi HAR under a strict cross-domain
protocol (train on a single environment, test on six unseen ones) and ask how
much of the domain gap can be closed \emph{without} the hand-engineered
front-end: first by \emph{learning} invariance with Supervised Contrastive
Learning (SupCon)~\cite{supcon} instead of engineering it, then by re-using the
receiver diversity that the dataset already provides. Both remedies are
data-efficient---they reuse the same small training set and a lightweight
encoder---and both compose with the orthogonal signal-processing tools of the
reference system. Every change is implemented and measured \emph{one at a time},
on top of the same baseline and the same protocol, so that each accuracy figure
is attributable to one design decision (\tab{tab:versions}). The contributions
are:
\begin{itemize}
  \item \textbf{Baseline (M.~Carraro).} A faithful reimplementation, in plain
  PyTorch, of the dataset pipeline and of the baseline Inception-style CNN, with
  a cross-domain evaluation protocol (train on $S1$, test on $S2$--$S7$) and a
  per-measurement-set error breakdown.
  \item \textbf{Contrastive representation (F.~Vezzani).} A deeper
  batch-normalized encoder pre-trained with a supervised-contrastive loss and
  domain-randomization augmentations, then evaluated with a linear probe on the
  frozen features. It improves cross-domain accuracy on every set.
  \item \textbf{Multi-antenna decision fusion.} A group identifier that survives
  the whole data pipeline recovers which windows are the \emph{same} physical
  time window seen by the four receiver antennas, so their predictions can be
  fused by averaging class probabilities---the largest gain we measured, with no
  retraining.
  \item \textbf{Front-end and optimization engineering.} A sliding window with
  the stride used by the SHARP authors ($30$ samples, $91\%$ overlap) replaces
  the na\"ive non-overlapping segmentation, supported by a two-pass,
  memory-bounded dataset builder; and a controlled comparison of learning-rate
  and early-stopping settings shows that, with a single training environment,
  fitting the training set better does \emph{not} imply generalizing better.
\end{itemize}
We use the full SHARP system~\cite{sharp} as the reference upper bound and
discuss, quantitatively, which part of the gap each strategy removes and which
part is left.
