\section{Reproducing the Experiments}
\label{sec:reproducibility}

The notebook downloads the dataset automatically, so no dataset files need to be
uploaded and no paths need to be edited. High-RAM is required with the reported \texttt{STRIDE = 30}: the windowed
dataset uses approximately \(20\)~GB at steady state and peaks near \(31\)~GB
while being built. If High-RAM is unavailable, set \texttt{STRIDE = 340} in section Section~2 of the colab; this uses non-overlapping windows but
produces fewer training samples and the corresponding lower accuracies.

A complete run on a High-RAM T4 takes approximately \(45\)--\(60\) minutes.
